# acm-solutions

洛谷 / ACM 刷题记录。每道题一个目录，里面是**自己写出来的**代码，加一段说清思路的注释。

## 目录约定

```
problems/
  P1706-全排列/
    main.cpp      # 代码，顶部写题号、思路、复杂度
    README.md     # 可选：卡在哪、错了几次、最后怎么过的
```

新建一题：

```bash
cp -r problems/_template problems/P1001-A+B
```

## 编译运行

```bash
g++ -O2 -std=c++17 -o main problems/P1706-全排列/main.cpp && ./main
```

## 规矩

- 看懂题解后**关掉重写**，写不出来就空着，不抄。
- 提交前自己想满 30 分钟；实在不行再问，问的是「哪一步卡住」而不是「代码给我」。
- 每过一题，把下面这行数字改大。
